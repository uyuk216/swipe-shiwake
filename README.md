# 爆速スワイプ仕分け

中央のお題を、画面に表示されたルールに合わせて左右へ仕分ける20秒ゲームです。スマホはスワイプ、PCは ← → キーまたは画面の左右をクリック。正解を続けてコンボを伸ばそう。

## ローカルで開く

`index.html` をブラウザで開くか、次のコマンドで起動します。

Macでは同梱の `ゲームを開く.command` をダブルクリックしても開けます。

```sh
cd ~/プロジェクト/スワイプ仕分け
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。終了するときはサーバー上で `Ctrl+C` を押してください。ビルドや追加依存はありません。
